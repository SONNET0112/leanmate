# 数据来源与未确认项

## 食物营养数据（`src/data/foods.json`）

- 43 条常见食物，每 100 克可食部。
- 全部 `sourceType: "estimated"`，来源标注「公开食物成分参考值（USDA FoodData Central / 中国食物成分表量级），录入时未逐条联网复核」，UI 显示「估算值」。
- 生重/熟重分条（鸡胸肉生/熟、米饭熟、燕麦生等），不混用。
- 升级方式：逐条核对 USDA FDC 或《中国食物成分表（第 6 版）》后改为 `verified` 并记录条目编号。

## AI 识别的数据优先级

1. **食物库命中**：模型返回合法 `foodId` → 用库内 per100g 数值，来源标「食物库」，编辑后仍以库为准。
2. **模型估算**：库外食物 → 用模型给出的 per100g，标「模型估算」+ confidence + 份量依据，允许用户改成库内食物（改名为库内名称会自动切回库数据）。
3. **离线匹配**：不调用模型，只用库内名称/别名 + 单位换算（碗 200g、份 150g、个 50g、两 50g…），库外食物进入「未匹配」提示手动添加。

模型只负责拆分与份量估计，**不作为营养数据库**；同一份描述两次识别的克数/热量可能不同，所以必须人工确认。

## 营养目标规则（`src/data/diet-rules.json`）

| 项 | 采用值 | 来源 |
|---|---|---|
| 基础代谢 | Mifflin-St Jeor | Mifflin MD, St Jeor ST, et al. Am J Clin Nutr. 1990;51:241-247 |
| 活动系数 | 1.2 / 1.375 / 1.55 / 1.725 | 通用活动系数，估算 |
| 热量缺口 | 450 kcal/日 | 按 7700 kcal/kg 粗算 ≈0.45 kg/周 |
| 热量下限 | 男 1500 / 女 1200 / 其他 1350 kcal | 常见保守下限 |
| 蛋白质 | 1.6 g/kg | Morton RW, et al. Br J Sports Med. 2018;52:376-384 |
| 脂肪 | ≥0.8 g/kg 且 ≥20% 热量 | 常规必需脂肪下限 |
| 碳水 | 剩余热量 / 4 | 使宏量热量与目标自洽 |
| `other` 性别 | BMR 常数 -78 | 男女常数均值，工程折中 |

蛋白质/碳水/脂肪系数与每日热量目标是两套独立参数：热量来自 TDEE-缺口，宏量来自体重系数与热量占比，互不覆盖。
